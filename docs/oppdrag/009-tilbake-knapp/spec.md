# APP-HAA oppdrag 09: Tilbake-knapp på «Slik kunne det sett ut for deg» og spørsmålene

Bestilt av Oleiv 17.11 kl. 12:52: det mangler en tilbakeknapp, så folk kan gå bakover og endre svarene sine.

## Beslutning
- «Slik kunne det sett ut for deg» (#ferdig): «Tilbake» står ved siden av «Seks korte spørsmål», både øverst og nederst, som på stegene før. Den går til «Korleis vil du få det?» (#kanal), og valgene står igjen.
- Spørsmålene (#svar): «Tilbake» står ved siden av «Send svara» og går til #ferdig. Svarene som er krysset av, står igjen. Knappen sender ikke skjemaet.
- Ingenting annet endres. «Tilbake» er oversatt fra før.

## Akseptkriterier
| Nr | Kriterium |
|---|---|
| K1 | #ferdig har «Tilbake» øverst og nederst, og den går til #kanal med valgene beholdt |
| K2 | #svar har «Tilbake» ved «Send svara». Den går til #ferdig, sender ingenting, og avkryssede svar står igjen når man kommer tilbake |
| K3 | «Tilbake» er oversatt på alle fem språk |
| K4 | Ingen horisontal overflyt i #ferdig og #svar på 375 og 320 px |
| K5 | Diff bare i #ferdig og #svar |
