# APP-HAA oppdrag 06: flere kanaler, to nye spørsmål og vennligere tekst

Bestilt av Oleiv 16.11 kl. 21:23. Valget av spørsmål ble gjort kl. 21:29 (alternativ 1: begge nye spørsmål).

## Beslutninger

- Nynorsk er fortsatt standardspråk. Det er valgt av AI på fullmakt, etter anbefaling som Oleiv ikke har innvendinger mot. Begrunnelsen: Hå er språknøytral, og nynorskandelen i skolen er 95 % (2016). Bokmål er ett trykk unna.
- Teksten under «Luftig tekst» nevner ikke dysleksi lenger.
- Straks og Snart kan ha flere kanaler. Straks: SMS, varsel i app, e-post. Snart: SMS dagen før, varsel i app dagen før, ukentlig e-post. Minst én kanal må alltid være valgt. Godt å vite er uendret.
- To nye spørsmål:
  - «Korleis får du med deg nytt frå kommunen i dag?» (flere valg)
  - «Kor gamal er du?» i grove aldersgrupper. Spørsmålet er valgfritt.
  Det blir seks spørsmål.
- Google-skjemaet har fått fire nye spørsmål. De gamle enkeltvalg-spørsmålene for Straks og Snart står igjen med de 7 svarene som allerede er kommet inn, men får ikke flere svar.
  - Straks (flere valg): entry.1231167071
  - Snart (flere valg): entry.58709819
  - Slik får du nytt i dag: entry.1553620
  - Alder: entry.519260362

## Akseptkriterier

| Nr | Kriterium |
|---|---|
| D1 | Luftig tekst-hintet nevner ikke dysleksi, på noen av de fem språkene |
| D2 | Det går an å velge flere kanaler for Straks og Snart. Den siste kan ikke velges bort. |
| D3 | «Slik kunne det sett ut» og årsoversikten viser alle valgte kanaler i riktig form, for eksempel «SMS og e-post» og «SMS dagen før og i e-posten kvar veke» |
| D4 | Sendingen gir én POST med alle valgte verdier til de riktige entry-ID-ene. Verdiene skal være nøyaktig lik alternativene i skjemaet. |
| D5 | De nye spørsmålene vises som spørsmål 3 og 5, er oversatt til nb, en, uk og pl, og alder kan stå tomt |
| D6 | Ingen horisontal overflyt (375 og 320 px, fem språk, Normal og Størst+luftig) i #kanal, #ferdig, #svar og #aaret |
| D7 | axe-core gir 0 brudd i #kanal, #ferdig, #svar og #aaret |
| D8 | Ingen JS-feil |
| D9 | Uavhengig kontroll uten høye eller middels funn innenfor oppdraget |
