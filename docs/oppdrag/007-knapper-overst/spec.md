# APP-HAA oppdrag 07: knappene øverst på «Slik kunne det sett ut for deg»

Bestilt av Oleiv 17.11 kl. 11:25 (svar «1» i samtalen APP · APP-HAA 02 Innspill til Hå kommune).

## Beslutning

- «Seks korte spørsmål» og «Sjå kva du ville fått gjennom eit heilt år» står øverst, rett under «Du valde …», slik som på startsida. Da kan folk trykke seg raskt gjennom.
- «Seks korte spørsmål» står også igjen nederst, så de som leser hele sida, slipper å scrolle opp igjen.
- Ingenting annet endres. Tida som måles (pameldtSek), stoppes før denne sida, så svarene kan sammenlignes med de åtte som allerede er kommet inn.

## Akseptkriterier

| Nr | Kriterium |
|---|---|
| K1 | På #ferdig er rekkefølgen: overskrift, «Du valde …», «Seks korte spørsmål», «Sjå kva du ville fått gjennom eit heilt år», Straks, Snart, e-posten, «Seks korte spørsmål» |
| K2 | Begge «Seks korte spørsmål»-knappene går til #svar, og «Sjå kva …» går til #aaret |
| K3 | Knappene er oversatt på alle fem språk (begge kopiene) |
| K4 | Ingen horisontal overflyt i #ferdig på 375 og 320 px |
| K5 | Ingen andre visninger er endret (diff bare i #ferdig og én ny lytter) |
